## 🧠 Tanglish Offensive Language Classifier

**Tamil-English NLP Classification System**

Fine-tuning and deploying an LLM-based system for multi-class offensive-language detection in Tamil-English social-media text.

**Highlights**

* 🧠 Fine-tuned **Qwen2.5-3B-Instruct**
* 📊 Dataset of **44,000 Tamil-English YouTube comments**
* 🛠️ Used **QLoRA / PEFT**
* 🎯 6-class classification
* 📈 Achieved **56% Macro F1 improvement** over the zero-shot baseline
* 🌐 Building a real-time moderation web application

**Tech**

`Python` `Hugging Face` `QLoRA` `PEFT` `React.js` `Node.js` `Groq API`
